01 · Why it exists

1,528 pull requests. 692 people. 1 maintainer.

Each one can switch off system packages on someone's TV, or touch a launcher that has to stay small. At the peak, 174 were waiting at once.

02 · How it decides

Six checks, one comment.

  1. 01No model

    Facts

    Folders, protected packages, conflicts with main, size, strings per language, new permissions or network use.

  2. 02Claude Opus 5.5

    Decide

    The repo's written rules, a checklist for this kind of PR, and the maintainer's past calls on the most similar PRs.

  3. 03Claude Sonnet 5

    Critic

    Before a code or judgement-call merge: what is the strongest rule-backed reason not to merge?

  4. 04GLM-5.3-flash

    Second opinion

    A cheaper model on every PR. If it points another way, the maintainer decides.

  5. 05No model

    Hard rules

    Fixed rules always win, and can only make a verdict more cautious.

  6. 06Output

    One comment

    A suggestion and a few labels, or “needs maintainer”.

  • ✓ Abstains when unsure
  • ✓ Some PRs always go to the maintainer
  • ✓ Unchanged pushes cost nothing
